## ЧАСТЬ 3. КАК РАБОТАТЬ — ЦИКЛ

### 1. Правишь файлы

- **Код** — `src/*.cpp`, `src/*.h`
- **Ассеты** — `game/`, `assets/`, `shaders/`
- **Карты** — `game/maps/*.mgs`

### 2. Собираешь

```powershell
cd "C:\Users\дмитрий\Desktop\microlight_sdk"
.\build.ps1
Что делает build.ps1:

Компилирует код из src/

Копирует game/, assets/, shaders/ в build/

Создаёт build/microlight.exe

3. Запускаешь
powershell
.\build\microlight.exe
4. Проверяешь
Меню — работает?

New Game → MapSelect — карты видны?

В игре — ходит, стреляет, NPC двигается?

5. Смотришь лог
Запуск с логом:

powershell
.\build\microlight.exe 2>&1 | Tee-Object -FilePath "$env:TEMP\game_log.txt"
Потом:

powershell
Select-String -Path "$env:TEMP\game_log.txt" -Pattern "loaded|error|failed|cannot" | Select-Object -First 30
Ищи:

Texture loaded — текстура загрузилась

Texture load failed — файл не найден

MLM loaded — модель загрузилась

error / failed — проблема

6. Если сломалось — откат
powershell
# Найти бэкап
Get-ChildItem "C:\Users\дмитрий\Desktop\microlight_sdk" -Directory | Where-Object { $_.Name -like "backup_*" } | Sort-Object LastWriteTime -Descending
powershell
# Восстановить
Copy-Item "backup_IMYA\src\main.cpp" "src\main.cpp" -Force
.\build.ps1

GameInfo: no 'GameInfo' node	BOM в gameinfo.txt	Пересоздать через WriteAllText
